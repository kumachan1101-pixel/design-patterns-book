# 書籍の掲載コード

Kindle本 **『デザインパターン C++ソフトウェア設計』** に載せているコードの一式です。
本文で追う **変更前** と **変更後** を、そのままビルドして動かせる形で置いています。

- リポジトリ: <https://github.com/kumachan1101-pixel/design-patterns-book>
- 著者: KumaKuma H.H.
- ライセンス: [MIT](LICENSE)

## どのフォルダを使うか

本を改訂してコードが変わったときは、フォルダを分けて追加しています。 **お手元の本の「おわりに」にある「掲載コードについて」で、書かれているフォルダ名を確かめてください。**

| 本の「掲載コードについて」の書き方 | 使うフォルダ |
|---|---|
| `volume01-rev2` フォルダの `run.bat` と書かれている（改訂後の本文） | [`volume01-rev2/`](volume01-rev2/) |
| `volume01` フォルダの `run.bat` と書かれている（最初に公開した本文） | [`volume01/`](volume01/) |

どちらも『デザインパターン C++ソフトウェア設計』（Strategy / State / Observer）の掲載コードです。Kindleで本を最新の内容に更新した場合は、`volume01-rev2/` を使ってください。以前の版のフォルダは、その版の本文と一致したまま残しています。

以下の説明では、改訂後の `volume01-rev2/` を例にします。`volume01/` でも手順は同じです。

## 動かす

### Windows：`run.bat` をダブルクリック

[`volume01-rev2/run.bat`](volume01-rev2/run.bat) をダブルクリックすると、次のようなメニューが出ます。番号を入れて Enter を押すと、その場でビルドして実行します。

```text
=====================================================================
 第1冊 掲載コードの実行      コンパイラ: g++
=====================================================================
   1  第1章 Strategy  変更前   フェーズ1の現状コード
   2  第1章 Strategy  仮実装   フェーズ3で構造を変えずに変更を当てたもの
   3  第1章 Strategy  完成     フェーズ7の完成コード
   4  第1章 Strategy  完成     実務のファイル分割版
   ...
   A  全部をビルドして実行する
   Q  終了
```

**C++ コンパイラが1つ必要です。** 入っていない場合は、下の「[Windows での注意点](#windows-での注意点)」の手順で先に準備してください。

### macOS・Linux：`make`

C++14 が通るコンパイラ（`g++` または `clang++`）と `make` があれば動きます。macOS なら、ターミナルで `xcode-select --install` を実行すると両方がそろいます。

```sh
git clone https://github.com/kumachan1101-pixel/design-patterns-book.git
cd design-patterns-book/volume01-rev2/ch01-strategy/1-before
make run
```

`run.bat` も `make` も使わずに、直接コンパイルすることもできます。

```powershell
g++ -std=c++14 -Wall main.cpp -o app
.\app.exe
```

## Windows での注意点

### C++ コンパイラが必要です

`run.bat` は、コンパイラを自分では入れません。`g++` → `clang++` → Visual Studio の `cl` の順に探し、どれも見つからなければ、入れ方を表示して止まります。

いちばん手軽なのは、MSYS2 で `g++` を入れる方法です。

1. <https://www.msys2.org/> からインストーラーを入れます。インストール先は既定の `C:\msys64` のままで構いません。
2. スタートメニューから **「MSYS2 UCRT64」** を開き、次を実行します。途中で確認されたら Enter を押します。

   ```sh
   pacman -S mingw-w64-ucrt-x86_64-gcc
   ```

3. Windows の環境変数 `Path` に `C:\msys64\ucrt64\bin` を追加します。スタートメニューで「環境変数」と検索し、「環境変数を編集」→ ユーザー環境変数の `Path` →「新規」で追加します。
4. **開いていたエクスプローラーやターミナルを、いったん全部閉じます。** `Path` の変更は、すでに開いているウィンドウには反映されません。
5. 新しく開いた PowerShell で `g++ --version` と入力し、バージョンが表示されれば準備完了です。あらためて `run.bat` をダブルクリックしてください。

### Visual Studio の `cl` を使う場合

`cl` はふつう `Path` に入っていないため、`run.bat` のダブルクリックでは見つかりません。スタートメニューから **「Developer PowerShell for VS」** を開き、使うフォルダ（`volume01-rev2` など）へ移動して次を実行します。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File run.ps1
```

### 警告が表示されたとき

ZIP でダウンロードして展開した場合、`run.bat` をダブルクリックすると「Windows によって PC が保護されました」と表示されることがあります。「詳細情報」→「実行」を押すと続けられます。表示させたくない場合は、展開する前に ZIP ファイルを右クリック →「プロパティ」→「許可する」にチェックを入れてから展開するか、`git clone` で取得してください。

### PowerShell の設定は変わりません

`run.bat` は、同じフォルダの `run.ps1` を呼ぶときだけ実行ポリシーを緩めます（`-ExecutionPolicy Bypass`）。PC 全体の設定は変えません。

### 作られるファイル

実行ファイルは一時フォルダ（`%TEMP%\design-patterns-book`）に作ります。リポジトリのフォルダには何も書き込みません。不要になったら、この一時フォルダごと削除して構いません。

### 日本語が文字化けするとき

`run.ps1` は、出力を UTF-8 に切り替えてから実行します。それでも化ける場合は、Windows Terminal で開き直すか、コンソールのフォントを日本語に対応したもの（MS ゴシックなど）に変えてください。

## このコードについて

- **学習用です。** 本文に書いたとおり、永続化・外部通信・例外処理・並行処理は入れていません。設計の構造を短く見せることを優先しています。そのまま本番環境へ持ち込む想定ではありません。
- **本文が正本です。** 掲載コードと同じ内容になるよう検査していますが、食い違いを見つけたら [Issues](https://github.com/kumachan1101-pixel/design-patterns-book/issues) で知らせてください。正誤表としても使います。
- **版ごとにフォルダを分けます。** 本文の改訂でコードが変わるときは新しいフォルダを追加し、以前の版のフォルダは変えません。同じ版の中の誤りを直すときは、そのフォルダを直し、変更内容をコミット履歴に残します。
